# DOSAI

**Dashboard for Optimizing Seamless Agent Interaction** (pronounced "doh-sigh")
is a planned local-first macOS control panel for coordinating and observing AI
software-development agents. It is intended to make agent activity visible,
bounded, auditable, and easier for a human operator to govern.

DOSAI is a private, pre-launch working product name. This repository does not
claim formal trademark clearance or affiliation with another company.

## Phase 0 Status

The project is in Phase 0 discovery and repository bootstrap. This phase records
the proposed architecture, defines capability proofs, and establishes security
and stop/go criteria. It does not implement the complete Electron application or
claim that direct Codex-to-Claude IPC exists.

**No production automation is authorized.** Phase 0 permits documentation,
read-only investigation, local validation, and explicitly bounded capability
proofs only. Production changes, Stripe Live actions, secret access, deployment,
and destructive mutations are out of scope.
